# V90.bk — Screen-by-Screen Web/Mobile UI + Role Dashboards

Adds a role-aware screen catalog and personal dashboard layout foundation over V90.bj's web/Android integration.

## Highlights
- role-scoped ERP screen catalog and `/v90bk/screens` API
- role-specific default dashboard widgets and `/v90bk/dashboard` API
- dashboard layout persistence for authorized roles
- screen/dashboard RBAC
- migration 136 and release metadata

This release remains cumulative from V90.bj.
