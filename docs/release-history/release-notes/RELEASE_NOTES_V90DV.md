# V90.dv — Workforce Labour Budget vs Actual, Benchmark Snapshots & Cost Variance

Migration 197 extends V90.du with configurable labour budgets, period actuals, benchmark snapshots, labour cost variance, overtime visibility and an efficiency index for management comparison.

## Scope
- Labour budget by organization/entity/department/product/period
- Labour actuals and overtime capture
- Budget vs actual hours, cost and output variance
- Labour cost variance percentage
- Efficiency index against budget cost per unit
- Snapshot API for auditable comparison
- Workforce budgeting dashboard UI/API
- RBAC permissions for budget, actual, snapshot and dashboard operations
