# V90.dw — Workforce Training Effectiveness & Certification Compliance

Cumulative release built on V90.dv.

## Added
- Training effectiveness measurement against pre/post labour productivity and labour cost per unit.
- Configurable effectiveness score and output/cost improvement percentages.
- Certification compliance check with configurable expiry warning window.
- Compliance statuses: COMPLIANT, EXPIRING, EXPIRED, INACTIVE and NO_EXPIRY.
- Auditable certification compliance snapshots by checked date.
- Workforce training/compliance dashboard and web UI.
- RBAC permissions for viewing, posting effectiveness and running compliance checks.
- PostgreSQL migration 198.
