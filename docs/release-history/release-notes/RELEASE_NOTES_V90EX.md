# V90.ex — Reliability Governance Closure + Executive Reliability Control

Schema target: **224**.

V90.ex completes the reliability governance control loop after V90.ew effectiveness assessment.

## Included
- Executive control score combining effectiveness, target attainment, exception exposure and governance score.
- Automatic promotion of ineffective changes into management exceptions.
- Critical/high exception prioritization.
- Exception resolution with accountable evidence/note.
- Executive control dashboard and period trend.
- Controlled period closure with unresolved-exception guard; `force=true` is an explicit management override.
- Closure record retains score and unresolved-exception count.
- No automatic maintenance-plan mutation or operational change.
- All recommendations remain approval-controlled through the existing V90.eu governance workflow.
