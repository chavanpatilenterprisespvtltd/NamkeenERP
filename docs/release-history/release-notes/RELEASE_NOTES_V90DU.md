# V90.du — Workforce Performance Benchmarking & Labour Cost Forecasting

Migration 196 adds configurable labour-efficiency targets, production labour performance benchmarking, efficiency/utilization metrics, target variances, production labour cost forecasting and a workforce benchmarking dashboard/API layer.

## Scope
- Labour efficiency targets by organization/entity/department/product
- Labour performance benchmarking
- Output/hour and labour cost/unit benchmarking
- Utilization and efficiency percentages
- Target and variance capture
- Production labour cost forecasts
- Forecast cost/unit and forecast variance
- Forecast confidence
- Period close control
- RBAC permissions
- Web UI
