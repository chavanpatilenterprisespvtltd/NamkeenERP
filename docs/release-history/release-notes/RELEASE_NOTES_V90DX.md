# V90.dx — Workforce–Payroll–Production Cost Reconciliation

Cumulative release built on V90.dw.

## Added
- Payroll employer-cost reconciliation against payroll labour allocations.
- Payroll allocation reconciliation against production labour capture.
- Labour budget versus production labour cost variance.
- Labour cost per unit from production labour capture.
- Configurable reconciliation tolerance.
- Reconciliation close control by organization/entity/period.
- Workforce cost reconciliation dashboard and web UI.
- RBAC permissions for view/reconcile/close operations.
- PostgreSQL migration 199.
