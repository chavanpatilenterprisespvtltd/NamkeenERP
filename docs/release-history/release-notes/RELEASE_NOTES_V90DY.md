# V90.dy — Workforce Productivity Benchmarking + KPI Targets

Cumulative release built on V90.dx.

## Added
- Configurable workforce KPI targets by organization/entity, department and product.
- Higher-is-better and lower-is-better KPI direction handling.
- Workforce KPI scorecards with actual, target, variance, achievement and efficiency score.
- Peer productivity benchmarking with participant count, best/worst, rank, percentile and gap-to-best.
- KPI period close control.
- Workforce productivity KPI management dashboard and web UI.
- RBAC permissions for target management, scorecards, benchmarking, viewing and close operations.
- PostgreSQL migration 200.
