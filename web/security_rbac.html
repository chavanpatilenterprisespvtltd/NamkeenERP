Security / RBAC & Scope

V90.fn control surface for persisted sessions, roles/permissions and organization/entity/location/warehouse scope.

Scope hierarchy

Organization → Entity → Location → Warehouse

No cross-organization scope should be granted. All grants/revokes are audited.

Operational note

This UI is a control surface only. It does not bypass backend authorization.
