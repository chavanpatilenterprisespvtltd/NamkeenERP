Mobile Inventory / Dispatch / Delivery Execution

V90.gt executes validated V90.gs mobile events against the existing ERP transaction system-of-record.

  • PICK_CONFIRM → confirms the existing pick list.
  • DISPATCH_CONFIRM → validates the existing posted dispatch.
  • DELIVERY_CONFIRM → records POD against the existing dispatch.
  • RETURN_CONFIRM → receives an existing return into QC hold.

Every execution is idempotent and retained in the mobile execution audit table.
