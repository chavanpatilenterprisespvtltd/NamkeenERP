Accounting Posting & Tally

V90.ca posting bridge. All mappings and entities are configuration-driven.

Capabilities
  • Sales invoice → accounting voucher
  • GST transaction → balanced accounting voucher
  • Inward GST → purchase/input-tax posting
  • Tally XML export with idempotency
  • Posting ledger and debit/credit reconciliation
APIs
POST /v90ca/accounting/post
POST /v90ca/accounting/post/sales-invoice/{invoice_id}
POST /v90ca/accounting/post/tax/{tax_line_id}
GET  /v90ca/accounting/postings?organization_id=...
POST /v90ca/tally/{posting_id}/export
