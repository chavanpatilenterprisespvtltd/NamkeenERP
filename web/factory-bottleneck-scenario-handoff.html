Factory Scenario Comparison & Handoff

Compare simulated bottleneck scenarios, approve a preferred scenario, then hand its actions to Manufacturing Scheduling.

Workflow

  1. Run V90.ed scenario simulations.
  2. Compare two or more scenario IDs.
  3. Approve the preferred scenario.
  4. Handoff the approved scenario to the scheduling work queue.

API endpoints

  • POST /v90ee/factory-bottleneck/scenarios/compare
  • GET /v90ee/factory-bottleneck/scenarios/comparisons/{comparison_id}
  • POST /v90ee/factory-bottleneck/scenarios/comparisons/{comparison_id}/approve
  • POST /v90ee/factory-bottleneck/scenarios/{scenario_id}/handoff
  • GET /v90ee/factory-bottleneck/handoffs

Safety

Handoff creates an auditable scheduling work queue. It does not silently rewrite production schedules.
