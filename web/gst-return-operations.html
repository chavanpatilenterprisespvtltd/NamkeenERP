GST Return Operations

Filing preparation, return sections, tax payments, acknowledgements and compliance sign-off.

Workflow
  1. Prepare filing snapshot
  2. Populate return sections and amendments
  3. Record tax payment/challan
  4. Capture filing acknowledgement
  5. Complete authorized sign-off
  6. Export statutory return pack
